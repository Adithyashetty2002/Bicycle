Access for everyone

Accessibility Statement

Our commitment to a usable, inclusive catalogue and enquiry experience.

Our aim: Everyone should be able to explore the bicycles, compare models, and send an enquiry comfortably.

Our approach

This site is designed to meet WCAG 2.2 AA on the core browsing and enquiry journeys. It uses responsive layouts, semantic landmarks, keyboard navigation, visible focus states, labelled form fields, contrast-aware colour, scalable text, and alternative text for meaningful product images.

What we test

Core pages and controls are reviewed for keyboard navigation, screen-reader support, browser zoom, mobile touch use, visible focus, and colour contrast.

Known limitations

Third-party content, user browser extensions, and future embedded services may create limitations outside the site team's control. Any confirmed issue that affects a core journey must be recorded here with a workaround and target date.

Feedback

If you have difficulty using this site, use the contact page to describe the page, control, or content that caused a problem. We will use that feedback to improve the experience.
